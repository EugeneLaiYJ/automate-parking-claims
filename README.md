While Learning to use the Laravel, Inertia and Svelte frameworks together to make an app,
I decided to make a small tool to help me automate my monthly receipt log directly into
a parking claim form. However this app will not be hosted online ever because it does not
authenticate users to use and only does one singular function, generating an excel file

Very limited in scope, only reads the file correctly from Touch N Go Card Transaction history
to be downloaded from their website. Data entries are only to be selected by specified month and not year.
hard coded plenty of information that are within the scope for filling out this form.

This is a starting point I feel comfortable making and learning, could potentially expand and create
my own personal app for myself some time down the line.
